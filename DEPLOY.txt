СТЕК: Laravel 12 + собственная админка (Blade, Alpine.js, Tailwind; перенесена из education3) + Nutgram (Telegram) + Gemini AI


------------------------------------------------------------
1. ТРЕБОВАНИЯ
------------------------------------------------------------

PHP 8.2+ (pdo_mysql, mbstring, openssl, tokenizer, xml, ctype, json, bcmath, fileinfo, curl, gd)
MySQL 8.0+
Composer 2.x
Node.js 18+ — только на машине разработчика: собранные ассеты админки лежат в public/build и коммитятся,
на хостинге Node не нужен.
Gemini API ключ (aistudio.google.com)
Telegram Bot Token (@BotFather)


------------------------------------------------------------
2. БЫСТРЫЙ ЗАПУСК (локально)
------------------------------------------------------------

  cp .env.example .env
  # → заполнить DB_DATABASE, DB_USERNAME, DB_PASSWORD
  # → заполнить TELEGRAM_TOKEN, GEMINI_API_KEY

  composer install
  php artisan key:generate
  php artisan migrate
  php artisan storage:link
  npm install && npm run build   # только для разработки: пересобрать ассеты админки

  # Админка (/admin): пускается ровно одна почта из ADMIN_EMAIL.
  # В .env задать ADMIN_NAME, ADMIN_EMAIL, ADMIN_PASSWORD (пароль не короче 12 символов), затем:
  php artisan db:seed --class=AdminUserSeeder
  # Если пользователь с этой почтой уже есть, сидер только обновит пароль, когда он изменился.

  # Начальный контент сайта: 12 экспертов и 9 новостей, перенесённые из старых Blade-массивов.
  # Фото прогоняются через WebP-конвейер админки в public/uploads. Безопасно запускать повторно.
  php artisan db:seed --class=ContentSeeder

  # Запустить всё одной командой (serve + queue + vite + логи):
  composer dev

4. ПРОДАКШЕН: первый деплой (shared hosting / cPanel)
------------------------------------------------------------

  # composer.phar уже в проекте (из git), vendor/ НЕ в гите.
  # Все команды — через /usr/local/bin/php

  /usr/local/bin/php composer.phar install --no-dev --optimize-autoloader

  php artisan key:generate
  php artisan migrate --force
  php artisan storage:link
  php artisan optimize:clear

  # Админ-панель (/admin): ADMIN_NAME, ADMIN_EMAIL, ADMIN_PASSWORD в .env, затем
  php artisan db:seed --class=AdminUserSeeder

  # Начальный контент публичного сайта (эксперты, новости); повторный запуск ничего не дублирует
  php artisan db:seed --class=ContentSeeder

  # Telegram webhook (указать свой домен)
  php artisan nutgram:hook:set https://womenhub.innovation.md/telegram/webhook

  # AI-эмбеддинги (после появления пользователей)
  php artisan ai:recompute-embeddings
