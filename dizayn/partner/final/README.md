# Логотипы партнёров — финальная папка

Готовые файлы для публикации на сайте.

## Что использовать

- `png/` — основной комплект PNG с прозрачным фоном или аккуратно подготовленным фирменным фоном.
- `svg/` — официальные векторные исходники там, где они доступны.
- `preview.png` — визуальная проверка всего комплекта.
- `manifest.json` — карта источников и обработки.

Все растровые файлы обрезаны по содержимому, очищены от технических полей и подготовлены в увеличенном размере для экранов с высокой плотностью пикселей. Логотипы не перерисовывались и не изменялись по цветам.

Для FinTech Moldova основной файл `png/Партнеры и вдохновители/06-fintech-hub.png` уже подготовлен на тёмном нейтральном фоне, чтобы белая официальная версия была видна на светлой карточке. Прозрачная версия сохранена в `png/Партнеры и вдохновители/transparent/06-fintech-hub.png`.

Первый логотип и два знака ООН использованы из файлов, которые были дополнительно предоставлены заказчиком.
