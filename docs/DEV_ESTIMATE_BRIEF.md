# Техническое описание проекта для оценки стоимости разработки

Проект уже написан и работает. Нужна оценка **стоимости разработки с нуля** (или стоимости полного повторения) силами команды; для сравнения ниже даны объёмы готового кода.

## 1. Суть в одном абзаце

Веб-платформа с четырьмя частями вокруг одной базы данных: **публичный сайт** (3 языка), **личный кабинет участницы** (3 языка), **админ-панель** (RU/EN) и **Telegram-бот** (3 языка) с ИИ-подбором контактов и платной подпиской. Бэкенд один, остальное — слои над ним.

## 2. Стек

| Слой | Технологии |
|---|---|
| Бэкенд | PHP 8.2+ (на сервере 8.3), Laravel 12, MySQL, очереди и планировщик (cron) |
| Фронтенд публичного сайта | Blade, «чистые» CSS и JS без сборки, две темы оформления |
| Админка | Blade, Tailwind CSS 3, Alpine.js, Vite 7 |
| Telegram | Nutgram (webhook, диалоги, inline-клавиатуры, WebApp) |
| Прочее | Intervention Image (GD), DomPDF, Purifier, ИИ-провайдеры (Gemini, OpenRouter, DeepSeek) |
| Хостинг | cPanel, общий хостинг, деплой через `git pull`, без Docker |
| Качество | PHPUnit: **997 тестов**, дымовой тест страниц (`npm run verify`) |

## 3. Объём (готовое)

44 миграции, 29 моделей, 51 контроллер, ~180 маршрутов, 161 шаблон Blade, 13 консольных команд, 3 фоновые задачи, ~17 000 строк PHP, ~10 000 строк CSS/JS, 92 файла тестов.

## 4. Функциональные блоки

### 4.1. Публичный сайт (3 языка: ru / en / ro)
- Главная (первый экран с анимированным чатом, направления, слово руководителя, эксперты, участницы-карусель, события, преимущества, шаги, цифры с анимацией, призыв, партнёры), «О платформе», «Приоритеты», «Положения» (документы с тарифами и разделами), Гала Премия, участницы (каталог с «показать ещё»), эксперты, события и публикации (карточки, детали, галерея с лайтбоксом), фото-альбомы, видео (встроенный плеер), партнёры (логотипы), проекты, возможности, контакты с формой (письмо на почту + раздел в админке, защита без капчи).
- **Две темы сайта**, переключаются в админке (тёмная и светлая); свой дизайн-слой, адаптив, режим экономии для слабых устройств, оптимизация под нагрузку.
- Контент трёхъязычный: тексты в БД (переводные таблицы) и в коде.

### 4.2. Личный кабинет участницы (3 языка)
- Вход через Telegram (одноразовый токен/WebApp), профиль (фото с обрезкой, описание, запрос, теги), модерация профилей, скрытие профиля.
- Подбор контактов: ИИ-векторы (эмбеддинги) + рейтинг совпадений, поиск, каталог людей, карточка человека.
- «Инициативы» (публикации возможностей участниц): создание, уведомления подходящим.
- ИИ-помощник (чат с базой знаний платформы), раздел «Знания».
- Платная подписка (несколько тарифов), доступ закрытых разделов по плану.

### 4.3. Админ-панель (русский и английский)
CRUD с трёхъязычными полями: события, публикации, эксперты, проекты, возможности, альбомы (загрузка пачкой, сжатие, сортировка перетаскиванием), видео, теги, подписчики. Профили участниц (модерация, скрытие, уведомления в Telegram), рассылки (Telegram + письма, очередь, статусы доставки), обращения с сайта, настройки сайта (темы, цены, контакты, ИИ-провайдеры, ключи, SMTP), настройки кабинета, тексты бота (правка прямо в админке, трёхъязычные), статистика с PDF-выгрузкой, тестовый ИИ-чат.

### 4.4. Telegram-бот
Регистрация и анкета (диалог), меню, ИИ-подбор контактов, публикация инициатив, уведомления, оплата подписки, справочный ИИ-ассистент, три языка, правка текстов из админки, массовые рассылки с ограничением скорости и повтором.

### 4.5. Платежи
Подписка через банковский веб-эквайринг (редирект на страницу банка, подпись и проверка уведомления, возврат пользователя, учёт платежей). Есть тестовая заглушка банка.

### 4.6. ИИ
Эмбеддинги профилей (асинхронно, очередь), ранжирование совпадений, чат-ассистенты (по знаниям платформы и для бота). Подключение и проверка нескольких внешних провайдеров, ключи хранятся в настройках.

## 5. Нефункциональные требования
- Три языка на сайте, кабинете и в боте; перевод интерфейса админки на английский (тест проверяет отсутствие русских слов).
- Безопасность: CSRF, очистка HTML, ограничения на загрузки, защита форм от спама без капчи, скрытые профили недоступны другим участницам.
- Производительность на слабых телефонах: минимум постоянных анимаций, отложенная отрисовка секций, обработанные картинки (WebP, миниатюры).
- Кэширование публичных страниц и его сброс при правках в админке.
- Документация: `docs/PROJECT_MAP.md` (карта проекта), `DEPLOY.txt`.

## 6. Внешние интеграции
Telegram Bot API; банк-эквайер; SMTP-почта; ИИ-API (Gemini, OpenRouter, DeepSeek); YouTube (встроенное видео).

## 7. Что нужно для оценки (по чему считать)
1. Дизайн: макеты не требуются, дизайн сделан в коде (две темы, ~10 типов страниц, ~160 шаблонов).
2. Контент: перенос ~100 новостей и альбомов, ~20 участниц, 15 партнёров уже сделан сидерами; тексты на трёх языках.
3. Основная трудоёмкость сосредоточена в: Telegram-боте с диалогами, ИИ-подборе контактов, подписке с банком, админке (много сущностей с переводами), двух темах сайта и покрытии тестами.
4. Не входит: мобильное приложение, платёжные системы кроме одного банка, сторонний CRM.

## 8. Ориентир по составу работ (для разбивки сметы)
Аналитика и архитектура — Бэкенд-ядро и база (модели, миграции, авторизация, права) — Публичный сайт, 2 темы — Кабинет участницы — Админка — Telegram-бот и рассылки — ИИ-подбор и ассистент — Платежи и подписки — Тесты и оптимизация — Развёртывание на cPanel и документация.
