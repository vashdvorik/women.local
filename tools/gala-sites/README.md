# Сайты гала-премии (gala2024, gala2025, gala2026)

Три самостоятельных статичных сайта (чистые HTML, CSS и JS, PHP и node на сервере не нужны). Лежат в корне проекта и в git целиком.

| Папка | Адрес | Что это |
|---|---|---|
| `gala2024/` | https://gala2024.innovation.md/ | Первая церемония (4 марта 2025): рассказ, фото (9), листаемый журнал 2024 (84 стр.) |
| `gala2025/` | https://gala2025.innovation.md/ | Церемония 12 марта 2026: рассказ, фото (17), видео, листаемый журнал 2025 (74 стр.) |
| `gala2026/` | https://gala2026.innovation.md/ | Анонс (церемония ещё не прошла): этапы, прошлые церемонии, видео, призыв присоединиться |

## Как выложить на сервер
1. `git pull` в проекте на хостинге.
2. В cPanel («Домены» или «Поддомены») для каждого домена укажите корень документов: путь к проекту + `/gala2024`, `/gala2025`, `/gala2026`.
   Больше ничего настраивать не нужно (`.htaccess`, `robots.txt`, `sitemap.xml` лежат в папках).
3. В Search Console добавьте каждый домен и отправьте его `sitemap.xml`.

## Как менять
Файлы `index.html`, `assets/style.css`, `assets/script.js` СОБИРАЮТСЯ: править их вручную не нужно (правки пропадут при сборке).
- Тексты и факты: `tools/gala-sites/data/{2024,2025,2026}.mjs` (каждая фраза на ru, en, ro).
- Дизайн и анимации (общие для трёх сайтов): `tools/gala-sites/src/style.css`, `src/script.js`.
- Листаемый журнал: `src/flip.js` и `src/page-flip.browser.js` (те же, что на основном сайте).

Сборка из корня проекта:

    node tools/gala-sites/build.mjs

Картинки (фото церемоний из `public/themes/public/miro/images/albums/gala-premiya-*`, страницы журналов из каталогов основного сайта
`zhenskiy-zhurnal-2024` и `zhenskiy-zhurnal-2025`) уменьшает и кладёт в папки сайтов скрипт:

    php tools/gala-sites/prepare-media.php

Он нужен только при смене фото или журналов. После сборки закоммитьте папки `gala2024`, `gala2025`, `gala2026`.
Проверка целостности: `php artisan test tests/Feature/GalaSitesTest.php`.

## Новый год
Добавьте `data/2027.mjs` по образцу, строку в `config/site.php` (`gala`), год в списки `build.mjs` и `prepare-media.php`, затем соберите.
